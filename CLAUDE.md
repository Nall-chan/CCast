# Diese Library: ChromeCast (GoogleCast)

- Diese Library dient zur Anbindung von Geräten, welche ChromeCast (GoogleCast) ausführen, an die Software IP-Symcon. Sie stellt die notwendigen Module und Funktionen bereit, um ChromeCast-Geräte in IP-Symcon zu integrieren und zu steuern.
- Die Library ist so konzipiert, dass sie leicht erweiterbar ist, um fehlende Abschnitte bei der Auswertung von ChromeCast-Paketen und Funktionen zu ergänzen.
